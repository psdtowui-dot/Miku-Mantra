# @maneet/ui

Independent design system, categorized icon collection, Framer Motion animation tokens, and UI feedback primitives extracted from the MikuMantra Luxury E-Commerce platform.

## Modules

- `@maneet/ui/design-system`: Colors, typography, spacing, shadows, breakpoints, and dynamic theme factory.
- `@maneet/ui/icons`: Accessible Lucide & SVG icons with custom sizing, stroke-width, colors, and aria-labels.
- `@maneet/ui/animations`: Framer Motion presets (fade, slide, scale, stagger) with reduced-motion compliance.
- `@maneet/ui/feedback`: Reusable Spinner, ModalBackdrop, StatusBadge, and ToastService.

## Installation (Internal Workspace)

```json
{
  "dependencies": {
    "@maneet/ui": "workspace:*"
  }
}
```
